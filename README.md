# NX2navi Hub

Ver [INSTRUCCIONES.md](INSTRUCCIONES.md) para el paso a paso.

Programa con ventana para descargar NX2navi (https://github.com/tangerineturtle1/NX2navi), organizar tus `.nup` y guardar los juegos convertidos. No hace falta saber de informatica.

## Como se usa
1. Doble clic en **Abrir NX2navi Hub.bat**.
2. Pestana **1. Instalar**: pulsa "Descargar / actualizar NX2navi" (solo la primera vez).
3. Pestana **2. Mis juegos (.nup)**: "Agregar archivos .nup..." y elige tus archivos (completos, en partes, o juego base + actualizacion). Se guardan juntos en una carpeta con el nombre del juego.
4. Selecciona el juego y pulsa **Convertir a nativo**. Se abre el instalador de NX2navi: sigue sus pasos.
5. Pestana **3. Juegos nativos**: elige el juego y pulsa **Jugar**.

`indice.md` se actualiza solo con el tamano y la fecha de cada juego.

## Notas
- NX2navi no usa `prod.keys`: el `.nup` ya viene descifrado.
- Segun su documentacion, solo soporta Ocarina of Time (Switch 2, v1.1.1). Otros juegos se pueden guardar en la biblioteca, pero no convertir.
- Base y actualizacion no se pueden unir concatenando archivos; se guardan juntos tal cual.
- No incluye archivos de juego: necesitas tu propia copia.
- Si algo falla, los detalles estan en `hub.log`.

## Aviso legal

No compartas tus .nup ni las compilaciones. Los juegos pertenecen a sus propietarios; este proyecto no esta afiliado a Nintendo ni al autor de NX2navi. Se ofrece sin garantia.
